# 内容契约

## 槽位

`attack` / `special` / `cast` / `dash` / `call` / `passive`

- cast = 探针 Spike
- dash = 闪步 Blink
- call = 越权 Override

## 稀有度

`C` / `R` / `E` / `H`

## ID

| 种类 | 格式 | 例 |
|---|---|---|
| 赞助端 | `patron_<id>` | `patron_grid` |
| 状态 | 英文短词 | `overclock` |
| 固件 | `boon_<patron>_<slot>_<key>` | `boon_grid_attack_arc` |
| 武器 | `weapon_<id>` | `weapon_blade` |
| 区 | `zone_<id>` | `zone_stacks` |
