# 一页纸

**中文名：**《外面》  
**英文名：**OUTSIDE  
**公司：**HADES（只是企业名）

## 一句话

你是 HADES 董事长的私生子。身上有回收芯片。你从塔楼打到城界，想去墙外见拒绝入籍的母亲。死了会被公司捞回家。大厅里的人每次都还在。街上的巨头给你装一局用的固件。夜一直在下雨。

## 不是什么

- 不是冥界、灵魂托管、死后世界
- 不是开放世界夜之城
- 不是枪战主循环
- 不是《哈迪斯》换皮；只借循环和关系系统

## 玩家每局在干什么

大厅换装 → 往上打区 → 挑门选奖励 → 装一局固件 → 死亡被召回 / 摸到墙外几分钟再被拖回。

## 成功标准

1. 死回大厅后，第三人能说出：「这是公司在召回资产，不是转生」。
2. 一局里能感到固件连携，不是随机加数。
3. 墙外很贵：短、安静、没有 HUD。
