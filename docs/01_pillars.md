# 支柱

冲突时先指这一页。

## 1. 死是物流，不是冥界

- 允许：创伤舱、无人机、父亲看到你被抬回来
- 禁止：灵魂、浴池、读条复活、无叙事的 Game Over

## 2. 五个动词吃掉所有战斗花样

- 槽位：普攻 / 特攻 / 探针 / 闪步 / 越权
- 允许：枪当特攻
- 禁止：枪战覆盖近战
- 冲突：手感 > 世界观设定

## 3. 赞助端是关系，不是商城

- 固件是加密来电，带立场
- 禁止：称之为神赐、无立绘 Buff 弹窗

## 4. 墙外很贵

- Outside 只有几分钟
- 禁止：通关后开放世界

## 5. 永远在夜里下雨

- 画面：雨、玻璃、广告比人高
- 禁止：希腊柱、桂冠、神殿、把 HADES 画成冥王
